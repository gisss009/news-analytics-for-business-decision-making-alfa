# Тестовые сценарии

Запуск для всех сценариев: `docker compose up` (или `python scripts/web.py` и `python scripts/dev.py`).
Автотесты: 208 тестов ядра (`cd backend && .venv/Scripts/python -m pytest -q`) и 11 тестов парсера
(`python -m unittest discover -s tests -t .`).

## Сводка `web/` — http://localhost:5174

| № | Шаги | Ожидаемый результат |
|---|---|---|
| W1 | Открыть главную | заголовок «Сводка для решений», кнопки «Разобрать событие» и «Новости», четыре компании, шесть вопросов разбора |
| W2 | «Разобрать событие» → «Дом торговли» | список событий компании (ставка, спрос, инфляция); у каждого строка «почему» и метка «Есть следующий шаг» или «Шаг не следует» |
| W3 | Вернуться «К компаниям» → «Северный прокат» | другой список событий: появляется «Цена проката и контракты» |
| W4 | Открыть событие «Ставка и стоимость денег компании» | блоки: что произошло, почему важно, риски и возможности, действие, оценка банка, на чём основан вывод, как собрано |
| W5 | В разборе нажать «Открыть материал» у обзора банка | открывается PDF обзора Альфа-Банка |
| W6 | Внизу разбора ввести «курс» → «Показать срез» | разбор той же компании по теме курса |
| W7 | Раздел «Новости» | лента деловых новостей с источником и временем публикации |
| W8 | «Войти» → телефон `+7 900 000-00-00`, пароль `demo1` (вход по логину — любой логин от 3 символов) | в шапке имя пользователя и кнопка «Выйти» (вход демонстрационный) |
| W9 | Удалить `data/out` и открыть сводку без выгрузки | сообщение «Нет файла выгрузки» вместо ошибки |

## Ядро и `frontend/` — http://localhost:5173

| № | Шаги | Ожидаемый результат |
|---|---|---|
| F1 | «Открыть сервис» | список синтетических компаний с поиском и выбором роли |
| F2 | «СтройИнвест Девелопмент», затем «Сибирское Золото» | ленты различаются: у застройщика — ставка, у золотодобытчика — курс и сырьё; у события «почему в вашей ленте» и значимость 0–100 |
| F3 | Открыть событие | шесть блоков; у каждого утверждения метка «Факт», «Аналитика Альфа-Банка» или «Вывод ИИ» и ссылки |
| F4 | Нажать ссылку у утверждения | открывается первоисточник: фрагмент новости или страница обзора |
| F5 | Блок «Самопроверка» | «Все ссылки открываются, числа совпадают с источниками», число итераций |
| F6 | Режим `--real` (ключ в `.env`), открыть новое событие | разбор пишет модель за 30–90 с, повторное открытие — из кэша |
| F7 | Режим `--real` без ключа или при исчерпанном бюджете | шаблонный ответ без ошибки, с той же структурой и метками |

## API — http://localhost:8000/docs

| № | Запрос | Ожидаемый результат |
|---|---|---|
| A1 | `GET /health` | `ok: true`, режим модели, число компаний и событий |
| A2 | `GET /clients/U_S0001/feed` | события с `score`, `reasons`, `topic` |
| A3 | `GET /events/{id}/insight?client=U_S0001` | `Insight`: блоки с `label` и `refs`, `verification.passed` |
| A4 | `GET /clients/NO_SUCH/feed` | ошибка в едином формате `{error: {code, message, trace_id}}` |
