## Выводы для загрузчика и синтетики

- Ключ — SYNTHETIC_U; дубль ID разрешать, оставляя первую строку и записывая предупреждение.
- Флаги приводить к bool, выручку к float; пустые строки → NULL с флагом `missing` в профиле.
- `REVENUE_COMPANY = 1000` считать сомнительным значением (низкая уверенность признака «масштаб»).
- Контрагент платежа может отсутствовать в таблице компаний: граф строится и по «внешним» узлам.
- Синтетика (`data/synthetic/`) повторяет эти имена файлов, поля, форматы и словари значений.
