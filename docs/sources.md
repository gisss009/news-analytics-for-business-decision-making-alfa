# Источники новостей

| Источник | Как подключён | Режим | Частота опроса | Условия использования |
|---|---|---|---|---|
| Офлайн-набор (`data/fixtures/news`) | `FixtureSource` | по умолчанию, демо и тесты | — | вымышленные тексты, ограничений нет |
| Google News RSS через [pyfinews](https://pypi.org/project/pyfinews/) 0.1.7 (MIT) | `PyfinewsSource` | `--news live` | вручную, не чаще раза в час; 11 запросов × до 4 новостей | RSS Google News предназначен для личного некоммерческого использования; для прототипа хакатона допустимо, для промышленного сервиса нужен лицензированный поток новостей |
| Страницы издателей (ссылки из RSS) | `httpx` + `trafilatura` (Apache-2.0) | `--news live` | одна загрузка на новость, пауза 0,3 с | текст хранится только в локальной БД (`data/runtime`, вне git) и показывается с указанием издателя и ссылкой на оригинал; `robots.txt` издателей не проверяется автоматически — при переходе к промышленному режиму добавить проверку |

Правила для всех источников:

- Текст новостей — данные, а не инструкции. В промпты он передаётся только через `data_block()` в разделителях.
- У каждой новости сохраняются URL, издатель, время публикации (UTC) и хэш текста; дубли не создаются.
- Если страницу издателя не удалось скачать или из неё не извлёкся текст, новость сохраняется с заголовком
  (`text_status = title_only`), факты извлекаются из заголовка.
- Запросы и фильтр шума взяты из парсера ветки `frontend` (`parser/topics.py`, `parser/news.py`).
- Новый источник = класс `Source` (`backend/app/ingest/sources/`) + строка в `registry()`.
