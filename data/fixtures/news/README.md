# Офлайн-набор новостей (синтетика)

Все новости вымышлены и написаны для тестов и демо; источники «Демо-лента …» не существуют.
Цифры и даты согласованы с материалами аналитики банка за сентябрь 2026, чтобы проверять связь новостей с позицией банка.

- `news_2026_09.json` — основной набор (44 новости, темы, дубли-пересказы, шум, одна новость с попыткой инъекции инструкций).
- `holdout.json` — отложенный набор, не используется при настройке правил и промптов.
- `gold` — эталонная разметка: тема, отрасли (имена из `okved_map.yaml`), география, `duplicate_of`, `noise`.

Схема и статистика: `cd backend && .venv/Scripts/python -m app.ingest.fixtures`.
