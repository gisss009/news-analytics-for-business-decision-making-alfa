# Синтетические данные (вымышленные)

Все записи в этой папке сгенерированы `backend/app/data/synthetic.py` (seed 42) и не являются данными банка.
Схема, имена файлов и словари значений повторяют датасет кейса (см. `docs/data-dictionary.md`).

Признаки синтетики: идентификаторы `U_S…`, `F_S…`, `group_S…`; названия компаний с пометкой «(синтетика)»
в `synthetic_company_names.csv` (этого файла в датасете кейса нет).

Пересоздать: `cd backend && .venv/Scripts/python -m app.data.synthetic`. Загрузить в БД: `python -m app.data.loader`.

Опорные компании для демо: U_S0001 (строительство, кредиты и лизинг), U_S0002 (золотодобыча, ВЭД, без кредитов),
U_S0003 (опт топлива, факторинг), U_S0004 (импорт продуктов из Китая и Турции, концентрация поставщика),
U_S0005 (IT, депозиты), U_S0006 (розница), U_S0007 (логистика, лизинг), U_S0008 (металлотрейдинг),
U_S0009 (агро), U_S0010 (импорт автомобилей).
